# 小圆助教 🌸

一个陪伴初中生学习数学的 AI 助教。通过温暖的对话式引导，帮助孩子**建立自信心**，逐步掌握**数学思维能力**。

[English Version](./README_EN.md)

> 教学理念完整继承自本仓库的 [《初中数学成长方案》](./初中数学成长方案.md)：
> 不做任务式逼迫，让孩子自我认同、主动执行；
> 碎片化定点补漏洞，绝不累积思维盲区；
> 尊重状态波动，深度与保底双模式，保护学习链条不断裂。

---

## ✨ 核心功能

| 功能 | 说明 |
|------|------|
| 💬 对话式引导 | 小圆姐姐不直接给答案，用提问引导学生自己想通 |
| 🌗 三种学习模式 | 深度成长（10–18分钟）/ 保底维稳（5分钟）/ 周末修复 |
| 📷 拍照传题 | 拍下题目照片，OCR 识别后小圆读题确认，再引导解题 |
| 🔍 盲区追踪 | 每次对话自动识别知识漏洞（区分概念漏洞 vs 计算粗心），星空图可视化 |
| ⭐ 知识星空图 | 沪教版知识图谱，掌握一个点亮一颗星星 |
| 🏅 成就徽章 | 盲区猎手、推导小勇士、错题侦探、不断链7天……奖励绑定思维成长 |
| 📖 学习记录 | 每次会话自动归档，可查看对话详情、可删除 |
| 😊 心情打卡 | 开场记录心情，小圆据此共情回应，尊重状态波动 |
| 🎤 情绪关怀 | 小圆先共情→闲聊→显示"开始学习"按钮，节奏由孩子掌握 |
| 🍅 番茄闹钟 | 选完模式自动计时，25分钟学+5分钟息，悬浮图标显示 |
| 📈 信心曲线 | 和自己比进步，不和别人比 |
| 🧭 错题两问协议 | 固定问法：①卡壳在哪一步？②思维漏洞是什么？ |
| 🎨 多主题切换 | 抹茶绿（默认）/ 樱花粉 / 薰衣草紫 |
| 🔑 API Key 配置 | 设置面板内直接输入自己的 DeepSeek Key，保存即生效 |
| 🚪 多用户切换 | 创建/删除档案，退出回到登录页，家人共用一台电脑 |
| 📝 教学日志 | 自动从对话中提取教学洞察，小圆越用越懂孩子 |

## 🚀 快速开始

### 方式一：桌面版（推荐，适合非技术用户）

1. 下载 `dist/Xiaoyuan` 文件夹
2. 双击 `安装.bat` 或直接运行 `Xiaoyuan.exe`
3. 浏览器自动打开，开始使用

### 方式二：源码运行（适合开发者）

```bash
# 1. 创建虚拟环境
python -m venv venv
venv\Scripts\activate        # Windows
# source venv/bin/activate   # macOS/Linux

# 2. 安装依赖
pip install -r requirements.txt

# 3. 启动
python run.py
```

浏览器打开 <http://localhost:8000> 即可使用。

首次进入时在设置面板（🎨）填入你的 DeepSeek API Key，保存后立即生效。

### 构建桌面版

```bash
# 安装 PyInstaller
pip install pyinstaller

# 构建
python build.py
```

生成的桌面版在 `dist/Xiaoyuan` 文件夹。

### 可选：拍照传题

```bash
pip install rapidocr-onnxruntime   # OCR 文字识别（首次运行自动下载模型约60MB）
```

安装后页面出现 📷 按钮，可拍照或上传题目图片。

### 使用流程

1. 首次进入创建学生档案（输入昵称）
2. 开场心情打卡 → 小圆先共情关怀 → 点击"开始学习"按钮
3. 选择学习模式（深度/保底/周末修复）
4. 和小圆聊天学数学，她会一步步引导你
5. 遇到不会的题可以点 📷 拍照发给小圆
6. 结束后在 🏅成长墙 → 📖学习记录 查看历史对话详情
7. 右上角 🚪 可退出切换账号

## 🧡 设计原则（小圆的行为红线）

- ❌ 绝不说「这么简单都不会」——卡壳时归因为「旧积木松了」，不是能力问题
- ❌ 绝不布置抄写、抄错题等形式主义任务
- ❌ 绝不推荐题海战术和秒杀技巧
- ❌ 绝不建议「回头整章重学」（新课正常跟进，碎片化定点补漏）
- ❌ 学生说累后绝不继续加码（立即降级保底模式或收尾）
- ❌ 绝不说「拍给我」——小圆收不到图片和语音，需要时请学生打字描述
- ✅ 说「我不懂」永远先被表扬诚实
- ✅ 表扬必须具体到思维动作（「你先找卡壳点再回课本，思路很棒」）
- ✅ 补到不影响新课理解即止（达标即止，不追求完美）
- ✅ 收到照片先复述确认题目内容，绝不装懂
