# 小圆助教 🌸

一个陪伴初中生学习数学的 AI 助教。通过温暖的对话式引导，帮助孩子**建立自信心**，逐步掌握**数学思维能力**。

[English Version](./README_EN.md) ｜ [完整设计方案](./docs/设计方案.md)

> 教学理念：不做任务式逼迫，让孩子自我认同、主动执行；碎片化定点补漏洞，绝不累积思维盲区；尊重状态波动，深度与保底双模式，保护学习链条不断裂。

---

## ✨ 核心功能

### 教学核心

| 功能 | 说明 |
|------|------|
| 💬 对话式引导 | 小圆姐姐不直接给答案，用提问引导学生自己想通 |
| 🌗 三种学习模式 | 深度成长（10–18分钟）/ 保底维稳（5分钟）/ 周末修复，快捷栏点选或打字均可 |
| 🔍 盲区追踪 | 22 类漏洞精细分类（概念/计算/读题/思维/粗心），附根因与修复策略 |
| 🧠 思维模型 | 10 大数学思维模型库，动态注入对话并显式化教学（🧩 标签） |
| 📈 掌握度评估 | 贝叶斯掌握度模型 + 置信度 + 遗忘衰减，比单点分数更可靠 |
| 🧭 错题两问协议 | 固定问法：①卡壳在哪一步？②思维漏洞是什么？ |
| ⭐ 知识星空图 | 沪教版（五四制）知识图谱 78 节点，前置依赖链 + 认知门槛标注 |

### 认知与心理

## 🚀 快速开始

### 方式一：桌面版（推荐，适合非技术用户）

1. 从 [Releases](../../releases) 下载 `Xiaoyuan.zip`
2. 解压后双击 `Xiaoyuan.exe`
3. 浏览器自动打开；系统托盘出现猫咪图标（右键可退出）

### 方式二：源码运行（适合开发者）

```bash
# 1. 创建虚拟环境
python -m venv venv
venv\Scripts\activate        # Windows
# source venv/bin/activate   # macOS/Linux

# 2. 安装依赖
pip install -r requirements.txt

# 3. 启动
python run.py
```

浏览器打开 <http://localhost:8000> 即可使用。

首次进入时在设置面板（🎨）填入你的 DeepSeek API Key，保存后立即生效。

### 构建桌面版

```bash
pip install pyinstaller
python build.py
```

生成的桌面版在 `dist/Xiaoyuan` 文件夹（需要连同 `_internal` 一起分发）。

### 可选增强

```bash
pip install rapidocr-onnxruntime   # OCR 文字识别（拍照传题，约60MB）
pip install pix2tex                # 公式识别（约500MB）
```

### 使用流程

1. 首次进入创建学生档案（输入昵称）
2. 开场心情打卡 → 小圆共情关怀 → 选择学习模式（快捷栏点选或打字）
3. 和小圆聊天学数学，她会一步步引导你
4. 遇到不会的题可以点 📷 拍照发给小圆
5. 完成后在 🏅成长墙 → 📖学习记录 查看历史对话详情
6. 右上角 🚪 可退出切换账号

## 🧡 设计原则（小圆的行为红线）

- ❌ 绝不说「这么简单都不会」——卡壳时归因为「旧积木松了」，不是能力问题
- ❌ 绝不布置抄写、抄错题等形式主义任务
- ❌ 绝不推荐题海战术和秒杀技巧
- ❌ 绝不建议「回头整章重学」（新课正常跟进，碎片化定点补漏）
- ❌ 学生说累后绝不继续加码（立即降级保底模式或收尾）
- ❌ 计算绝不心算——必须经 SymPy 校验
- ✅ 说「我不懂」永远先被表扬诚实
- ✅ 表扬必须具体到思维动作（「你先找卡壳点再回课本，思路很棒」）
- ✅ 补到不影响新课理解即止（达标即止，不追求完美）
- ✅ 收到照片先复述确认题目内容，绝不装懂
